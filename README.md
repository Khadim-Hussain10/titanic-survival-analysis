# Titanic Survival Analysis

Exploratory data analysis and machine learning on the Titanic dataset from Kaggle.

## What I did
- Cleaned missing values (Age, Embarked, Cabin)
- Visualized survival by sex, class, age and family size
- Trained a Random Forest model
- Compared models with 5-fold cross-validation
- Tuned tree depth to reduce overfitting

## Results
- Kaggle leaderboard score: 0.77990
- Women survived far more often (74%) than men (19%)
- Higher class passengers had better survival chances

## Tools
Python, pandas, NumPy, Matplotlib, Seaborn, scikit-learn
